## 📖 About

This repository contains practical implementations of algorithms studied in **Analysis and Design of Algorithms (ADSA)**. It covers sorting, hashing, tree traversal, graph algorithms, greedy techniques, dynamic programming, and backtracking.

## ▶️ How to Run

1. Install a Java Development Kit (JDK).
2. Clone or download this repository.
3. Open the required `.java` file in VS Code.
4. Compile and run the program from the terminal.

```bash
javac P01_Merge_Sort.java
java P01_Merge_Sort
```

Replace the filename and class name with those of the practical you want to run.

## 🎯 Learning Objectives

- Understand algorithm design techniques.
- Implement algorithms using Java.
- Learn sorting, searching, graph, and tree algorithms.
- Explore greedy, dynamic programming, and backtracking approaches.
- Understand time and space complexity.
